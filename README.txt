SwiftDictionary English Expansion v12

This update expands the English course from 453 to 550 entries by adding 97 less-common technical, scientific, historical, and professional terms.
The Chinese course remains unchanged at 106 entries.

Install:
1. Back up your currently working index.html.
2. Replace only index.html with the index.html in this package.
3. Do NOT replace supabase-config.js; keep your working Supabase URL and publishable/anon key.
4. Commit/publish the change to GitHub Pages and wait for deployment.
5. Test search, course switching, sign-in/out, saved words, and account separation.

This bundle contains only index.html and this README so it cannot overwrite your Supabase configuration.
