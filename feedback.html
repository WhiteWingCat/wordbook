Feedback & suggestions

Found a typo, a pronunciation issue, a confusing definition, or an idea for a new feature? Tell us about it.

SwiftDictionary is a static website, so this form prepares a GitHub feedback issue rather than sending data to a private server. Submitting the issue requires a GitHub account. You can also copy your feedback and share it another way.

Please avoid including passwords or other sensitive personal information.
